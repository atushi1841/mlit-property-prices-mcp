# MLIT Property Prices MCP

日本の国土交通省「不動産取引価格情報（XIT001）」を AI エージェントから検索できる MCP サーバーです。

## インストール（MCP公式レジストリ）

```bash
npx @modelcontextprotocol/inspector
```

公式レジストリ: `io.github.atushi1841/mlit-property-prices-mcp`
